### Fixed
- **Authors whose middle initials differ are no longer matched as one person** (#2881). "J. R. Smith" and "J. T. Smith" used to count as a confident match, so an import or a provider lookup could file one author's books under the other. Names whose initials disagree at the same position, and names where one side only drops an initial ("A. Smith" against "A. B. Smith"), now need a person to confirm them instead. The usual spellings of one author still match on their own: "J.R.R. Tolkien", "J. R. R. Tolkien", "JRR Tolkien" and "John Ronald Reuel Tolkien" are still the same person. A short first name is also no longer read as a run of initials, so "Ann Leckie" is not treated as the same name as "A. N. N. Leckie".

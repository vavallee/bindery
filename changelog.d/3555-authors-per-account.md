### Changed
- **Two accounts can follow the same author** (#3555). With multiple users and `BINDERY_ENFORCE_TENANCY` on, an author used to belong to whichever account added it first, so everyone else got a 409 on Add Author and on Add Book for any of that author's books. Now each account gets its own copy of the author, with its own monitoring, profiles and root folders, and sees only its own. Books are still held once per instance, so a book another account already has still answers "book is held by another user". Hardcover list syncs, requests and series checks give the account its own copy too, and deleting an account folds its authors into the receiving account's copy when it has one. With tenancy off nothing changes: one row per author and the same 409 as before.
- **The upgrade rebuilds the authors table** (#3555). The first start on this version rebuilds `authors` and `author_identifiers` to key them per account. Every row, id and setting is kept and nothing under an author is touched, but take a backup first as for any upgrade, and expect the first start to take a little longer on a very large library.

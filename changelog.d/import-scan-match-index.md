### Changed
- **Import from a folder scans large libraries much faster.** Scanning a folder used to compare every file against every book in the catalogue, so a 1000 file scan took close to two minutes against a 40,000 book catalogue and longer still on bigger ones. Bindery now builds a lookup of the catalogue's titles and ASINs once per scan and only compares each file with the books that could match it, and checks for already imported hardlinks by file identity instead of against every tracked file. The matches themselves are unchanged: the same files match the same books, and the same book wins when several match.

### Fixed
- **Import from a folder reads release folder names properly.** A folder like "The War of the Worlds - H. G. Wells [m4b]" used to come out with the author "H G", so the suggested metadata search found nothing. Initials now keep their dots, tags such as [epub], (Unabridged), a year in brackets or an ASIN in braces come off the title and author, and a release folder with no author in its name, like "TEST-bare [epub]", no longer has its whole name shown as the author.

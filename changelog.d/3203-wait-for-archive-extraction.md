### Fixed
- **RAR-packed torrent releases wait for an unpacker instead of being blocked** (#3203). Bindery does not unpack archives, and a completed torrent holding only a RAR set spent an import retry on every poll and was blocked about 90 seconds after completing, before an unpacker such as unpackerr had started. It now waits without spending retries, says in the Queue that it is waiting for the archive to be extracted, and imports once the extracted files appear in the torrent's folder. In copy and hardlink mode the archive volumes stay out of the library, with the client; in move mode they move with the folder rather than being deleted, except in a per-file move, where they stay in the download folder. If nothing extracts it within about 30 minutes, the download is blocked with a message naming the archive. Storage and Hardlinks gains a section on setting up unpackerr.

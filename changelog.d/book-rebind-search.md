### Added

- Add search-and-select metadata re-binding for OpenLibrary works and Hardcover books to the book Re-bind dialog, with upstream Links menus, alongside exact provider ID entry (including Enter-to-submit) and the existing author-mismatch confirmation. OpenLibrary editions remain viewable upstream but cannot be selected for re-binding. Results already in the library are marked and linked; records owned by another library book cannot be selected. The dialog is translated into all eight supported languages. Refs #492, #515.

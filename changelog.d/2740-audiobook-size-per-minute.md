### Changed
- **Ranking normalises the audiobook size bonus by the book's runtime, and caps the grabs bonus** (#2740): the size term rewarded total bytes, so of two releases of the same book the larger file always gained more, whatever its bitrate. When a book has a stored runtime an audio release is now scored by its density in MiB per minute at the same points-per-MiB the flat term used for a ten-hour book, so a ten-hour book is scored exactly as before and a shorter or longer one is no longer rewarded or punished for its length. The grabs term is capped at 100 grabs, so a release with thousands of downloads can no longer dominate the format and size terms. A book with no stored runtime scores exactly what it scored before, and `duration_seconds` is only filled from Hardcover, Audible, Audnexus with an ASIN, or an Audiobookshelf import, so on a default install the normalised path is rarely reached.

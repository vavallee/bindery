### Fixed
- **Requesters can ask for a book Bindery knows but has no file for** (#3898, #3908), a search result showed "In your library" with nothing to click whenever the book only existed as metadata. Now the book shows a Select button and the request goes through, and approving it adds the missing format to the existing book. The badge stays only when both formats are covered, with a file or already monitored, and when just one format is missing the request dialog offers only that one. With tenancy on, a book that belongs to another account shows Select like any book you do not have, and the request is then refused as already in the library. A request for a book that is already in the library waits for an admin to approve it, even when the account has auto-approve on. Thanks flaevers for the report.

### Security
- **Shared authors and books can only be changed by an admin when tenancy is on.** With `BINDERY_ENFORCE_TENANCY` set, a user who was not an admin could delete, merge, edit or refresh an author or book that had no owner, and act on automatic downloads and pending releases for such books. Because a shared author can hold books from several libraries, that let one user delete other users' books (and their files), move them under their own author, or change their monitoring and root folders. Adding an author or a book could also rewrite a shared author or adopt a shared book. Rows with no owner are still visible to every user, but only an admin can change them now, whether directly or through an add, and a user can no longer delete or merge one of their own authors while it holds a book from someone else's library. Tenancy off and admin accounts behave as before.

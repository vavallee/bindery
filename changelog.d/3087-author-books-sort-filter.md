### Added
- **Sort and more filters on an author's page** (#3087). The book list on an author's page has a Sort control: title ascending or descending, published newest or oldest, and added newest or oldest. It works in grid view and on phones, where the only sort before was a column header that is not shown. The Title column header sorts as well as Published. Two filters join Type, Status and Published: Monitored, and Language, which appears only when the author's books are in more than one language and treats spellings such as `en` and `eng` as the same language. Books with no release date now sort last instead of first.

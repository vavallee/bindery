### Added
- **Cluster-based noise filtering** (#2235) — an opt-in `internal/metadata/filterengine` signal that cross-checks each candidate work against how well-attested it is across every provider record sharing its title, on top of the scored-signal engine from #2235's first PR. New metadata profile setting **Cluster-based noise filtering** (Off by default) with three server-tuned presets — Conservative, Balanced (recommended), Aggressive — no raw scoring numbers exposed. Validated offline against `fiction-author-dataset`'s 1,422 hand-verified rows across 20 authors (CC-BY-4.0): isolating one known, filtering-unsolvable pen-name misattribution in that dataset, the Balanced preset scores recall=90.9%/precision=83.7% on the other 19 authors. Off (the default for every existing profile) is byte-identical to current behavior.
- **`AuthorSyncSummary.skippedThinCluster`** — a new sync-summary counter (and sample) for works dropped by the cluster filter's exclude branch, surfaced the same way every other `skipped*` reason already is.

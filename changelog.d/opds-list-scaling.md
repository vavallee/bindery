### Changed
- **OPDS author and recently added feeds no longer slow down as the library grows.** Opening Authors in a reading app took about a second on a library of 40,000 books and 2,000 authors, and Recently Added about 0.6 seconds, because Bindery asked the database for each author's books in turn and loaded every imported book to find the newest 50. Both are now answered by a single query each (Authors about 25 ms, Recently Added about 3 ms at that size), with the same entries in the same order. A user's Series feed on a multi user install gets the same treatment. Upgrading adds one small index to the books table.

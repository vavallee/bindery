### Security
- **A download grabbed without a book now only lands in a book its owner can see** (#3587). With `BINDERY_ENFORCE_TENANCY` on, a release a user grabbed from the Search page without picking a book could be matched, once it finished, to a book in another user's library and imported there. Bindery now matches such a download only against the owner's own books and books nobody owns. If nothing there matches, it stays in the queue as unmatched, as it always has when nothing matches. Downloads grabbed by an admin, automatic grabs, and installs with tenancy off match against the whole library as before.

### Fixed
- **Rename files can bring back an ebook's lost file extension** (#3217). A template with no dot before `{ext}`, such as `{Title}{ext}`, turned `Title.epub` into `Titleepub`, and fixing the template afterwards could not restore it because the extension was read from the current name. Bindery now takes it from the file's rename history or its contents, and refuses any move whose ebook name would have no extension. The audiobook folder template no longer saves with `{ext}`, which left folders named `Title.`, and the ebook template warns when there is no dot before `{ext}`. Reported by zoucet.

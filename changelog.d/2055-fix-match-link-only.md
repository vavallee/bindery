### Fixed
- **Fix match no longer moves your file unless you ask it to** (#2055). Fixing a match used to run the full import, so the file was moved into the chosen book's folder and renamed from your naming template, replacing your own layout. After you pick the book, Fix match now asks what should happen to the file, and the default, **Correct the match only**, leaves it exactly where it is under its current name and only changes which book it belongs to. **Also move and rename the file** is still there for when you want Bindery's layout, and still shows the destination before you confirm. API callers that leave out the new `relocate` field get the old move behaviour.

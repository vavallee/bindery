### Fixed
- **Authors whose metadata profile was deleted no longer lose their language filter** (#4132). Add Book and the Add Author API gave new authors a hard coded profile 1, so after you deleted that profile the author pointed at nothing, and search, import, catalogue sync and reconcile each treated that differently: search filtered nothing, import fell back to the preferred language, sync allowed English only and reconcile gave up. They now share one rule. An author's own profile is used if it exists, otherwise the new Default metadata profile for new authors setting under Settings, Metadata Profiles (empty means the first profile that exists). New authors get that default on every path, deleting a profile that authors still use is refused with the number of authors affected (or move them in the same step), the author page warns when its profile is missing, and upgrading repoints existing orphaned authors. Thanks to BraynArts for the detailed report.

### Added
- **Grab from Soulseek** (#1717). With a slskd client enabled, the Grab button now works on Soulseek results in interactive search. Bindery asks slskd for the files of the folder you picked, shows the download in the Queue with the peer's name and its place in the peer's upload queue, and imports the finished files through the normal import. The files land in slskd's downloads folder under a folder named after the download's id, so slskd and Bindery have to share that volume or the client's path remap has to reach it. A download counts as finished only when every file arrived. If one file fails, the whole download fails and is cleaned up, and a download that sits queued for 30 minutes or receives no bytes for 10 minutes is cancelled in slskd and failed, so you can pick another result. Removing it from the Queue cancels it in slskd. Files from peers are checked in block mode on import: a wrong format, an EPUB or Kindle file that will not open or is a different book, audiobook tags for another book, or a language your profile does not allow is refused and blocklisted, unless you set that content check to off. PDF has no content check. Grabbing is by hand only. Auto grab from Soulseek is not included, and the automatic search for wanted books still never uses Soulseek.

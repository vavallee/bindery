### Fixed
- **A second book with the same file name now imports beside the first** (#3560). When two books render to the same file name, for example the same title under two authors with the same name, the second import used to stay blocked for good. It now lands next to the first as "Name (2).epub", and Reorganize treats that file as already in place. An untracked file already sitting at the destination is no longer overwritten; the import picks the next free name instead. When an import does still block on a path another book holds, the message no longer points users who are not admins at Fix match, which only admins can run; it tells them to ask an admin.

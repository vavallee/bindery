### Changed
- **Auto approve now covers books already in your catalogue** (#3954). A request from an auto approving account for a book Bindery already has a row for, but not the file, used to sit in the queue waiting for an admin. Now it approves itself: the requested format gets monitored on that one book and a search starts, the same as an admin pressing Approve. For existing installs this means requests from auto approving accounts for unmonitored or partly monitored catalogue books no longer wait. A book an admin skipped still waits for a person, and nothing else about the book or its author changes. Thanks to flaevers for the report.

### Docs
- **Calibre on a Windows desktop runbook** (#2834): a step by step guide for connecting the Calibre desktop app on Windows through the Bindery Bridge plugin, built from a real setup. It covers using the share address instead of a mapped drive letter, installing and checking the plugin, the firewall rule and network profile, a fixed address for the PC, what each Test connection message means, reading the Push all results, and rerunning Push all to recover. The user guide gains Quick answers for the Calibre symptoms seen along the way, including how to get books onto a Kobo.

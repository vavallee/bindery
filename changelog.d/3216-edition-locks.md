### Added
- **Editions have field locks** (#3216). `PUT /api/v1/book/{id}/edition/{editionId}` sets an edition's publisher, publish date, ISBN-13, ISBN-10 and ASIN and locks each one whose value changes, so writing back an edition as GET returned it locks nothing. `publishDate` takes `YYYY-MM-DD` or the RFC 3339 timestamp GET returns, and `publisher` is capped at 500 bytes; both edition upserts honor the lock inside the write, including when they would otherwise fill an empty column. The PUT answers 409 when an import or another edit changed the edition while the request was being handled. `GET /api/v1/book/{id}` now carries the book's `editions` when it has any, each with its `lockedFields`, so a client can find the `editionId` to edit. A re-bind keeps an edition with a lock instead of dropping it with the old record's other provider editions (migration 135). Thanks chemicalsno.

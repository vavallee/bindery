### Fixed
- **Import preview counts a title held twice as one book** (#1927). When the source lists the same title as an ebook and again as an audiobook, the preview said two books would be created while the real import made one book and linked the second to it. The same went for that book's series, counted twice, and for an author spelled two ways, like Jane Austen and Austen, Jane, which the preview counted as two authors. The preview now counts these the way the import does.
- **No more scary relink message on every book** (#1927). "book relink skipped: upstream book match was ambiguous" showed up on books and authors that already had their metadata link, where nothing needed fixing. It now only appears when a book or author has no provider link yet and several equally good matches were found, and it says so in plain words: not linked to a metadata provider, none was picked.

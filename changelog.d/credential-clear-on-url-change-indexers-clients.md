### Security
- **Saved indexer, Prowlarr and download client credentials are cleared when the address changes.** Editing an indexer or Prowlarr URL to a different server without typing a new API key now clears the saved key instead of keeping it for the new address. The same applies to a download client when its type, host, port, TLS setting or URL base changes: the saved API key, password and proxy password are cleared unless you enter new ones in the same save. Enter the credentials again after moving to a different server. A trailing slash, capital letters in the host or an explicit default port do not count as a move. The indexers synced from a Prowlarr connection keep their own key until the next sync.

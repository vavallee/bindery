### Security
- **Login free modes now check the host name.** In `local-only` and `disabled` auth mode a web page could reach Bindery through your browser by pointing its own DNS name at Bindery's address, then act as the administrator. Those modes now skip the login only for IP addresses, `localhost`, single label names like `bindery`, and names under `.local`, `.lan`, `.home.arpa`, `.internal` or `.localdomain`. If you open Bindery by a name of your own such as `books.example.com` in one of these modes, add it to the new `BINDERY_ALLOWED_HOSTS` setting (`*.example.com` covers a whole domain), or sign in. The default `enabled` mode, API keys and signed in sessions are not affected.

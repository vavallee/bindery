### Fixed
- **Automatic grabs no longer pick dead torrents** (#3953). Bindery now reads the seeder count your torznab indexer reports. A torrent showing 0 seeders is skipped for the next release, and if every candidate is dead nothing is grabbed and the book stays Wanted so a later search can find a seeded copy. Among torrents of the same quality, more seeders now ranks higher, though never enough to beat a better format. Torrents whose indexer does not report seeders and usenet releases behave as before, and the manual search page still lets you grab a zero seeder release by hand. Thanks n1coh for the report.

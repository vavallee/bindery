### Fixed
- **Automatic grabs no longer pick dead torrents** (#3953). Bindery now reads the seeder count your torznab indexer reports. A torrent known to have 0 seeders is skipped by automatic grabs in favour of the next release, and if every candidate is dead nothing is grabbed and the book stays Wanted so a later search can find a seeded copy. A torrent whose indexer does not report seeders is treated as unknown and behaves as before, and so does usenet. Seeders also now break ties between otherwise similar results, but only as a small tie-breaker. The manual search page still lets you grab a zero seeder release by hand. Thanks n1coh for the report.

### Changed
- **Settings that save on change now confirm it with a message** (#3991). Import Mode, the interval selects, the toggles and the other settings that save the moment you change them used to do it silently, so you had to reload the page to see whether a change had stuck. Each one now shows a short message such as "Import Mode set to External", and a red "Couldn't save" message when the save fails. Fields with their own Save button keep their Saving, Saved and Error button.

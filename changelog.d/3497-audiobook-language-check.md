### Fixed
- **Audiobooks are now checked for language at import** (#3497). The release name filter cannot tell that `Dungeon Crawler Carl EspanolNeutro m4b` is Spanish, and until now an audiobook never got a second look the way an EPUB does. When a download finishes, Bindery reads the language tags in the audio files (ID3 `TLAN`, an MP4 `LANGUAGE` atom, a Vorbis `LANGUAGE` comment) and, if most of the tagged tracks are in a language the author's metadata profile does not allow, blocks the import, blocklists the release and searches again. Files with no language tag are never rejected, one stray track will not block a release, and manual import is untouched. Thanks to jh11-web for the report.

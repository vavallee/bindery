### Fixed
- **A Hardcover series can no longer end up as two series** (#3368): a series you added by hand and linked to Hardcover used to get a twin the next time an author sync, Audiobookshelf import or Hardcover list sync saw the same Hardcover series. Those paths now file their books under the series you already have. Linking a second series to a Hardcover series that is already taken is refused with a message naming the first one, and automatic linking skips it. Libraries that already have a pair are not touched, but Bindery now logs the pair at startup so you can merge it.

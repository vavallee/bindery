### Added
- **Open in BookOrbit link on the book page** (#1927). A book that a BookOrbit import matched or created now remembers its BookOrbit id, and its page shows an "Open in BookOrbit" link that opens the book in BookOrbit in a new tab. Only admins see it, since it comes from the BookOrbit settings. Books handed off through External mode but never imported from BookOrbit have no link, and neither does a book whose import match was ambiguous. If your browser reaches BookOrbit at a different address than Bindery does, set the new "BookOrbit address for your browser" field on Settings, BookOrbit. Leave it empty and the link uses the server URL.

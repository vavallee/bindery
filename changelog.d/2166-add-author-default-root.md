### Fixed
- **Add Author now honours the default root folder** (#2166) — the dialog seeded its root-folder picker from the first folder in the list rather than from `library.defaultRootFolderId`, and posted that as an explicit per-author choice. Since an author's own root folder is resolved ahead of the install default, the setting had no effect on anything added through the dialog. Invisible with one root folder configured; with two it silently filed authors under whichever was created first. The picker now starts on the configured default, falling back to the first folder when the default is unset or names a folder that has since been deleted.

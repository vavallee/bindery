### Added
- **Request front ends can file a request as the person who asked** (#3337). `POST /api/v1/requests` takes an optional `forUser` user id from an admin session or the API key, so an app that keeps its own users can make each request as that person instead of as the first admin. The request is theirs: it shows on their My requests, counts against their pending limit, and approves itself only if their account has auto-approve on. Requests shows who actually made it, "made for them with the API key" or "made for them by" an admin. Anyone else who sends `forUser` gets 403, and nothing changes for requests made without it. Adds one database migration.

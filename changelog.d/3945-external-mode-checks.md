### Fixed
- **External mode now checks the file before it drops it** (#3945). If you use External import mode with a drop folder, the language check and the ebook and audiobook content checks used to be skipped, so a wrong book went straight into the folder your other tool watches, with no warning and nothing in History. They now run first, with the same settings as a normal import. On warn, the default, the file is still dropped and the finding shows on the drop's History entry. On block, or when the language is not allowed, nothing is dropped and the download is parked as blocked with the same message as a normal import. External mode without a drop folder is unchanged.

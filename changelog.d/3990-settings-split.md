### Changed
- **The General settings tab is now four tabs, each with a one line description** (#3990). General was one long scroll. It now holds only Appearance and Security. File Naming (import mode, content checks, drop folders, import source folders, the metadata.opf sidecar and the three naming templates) is its own tab under Library. Storage (the download and library folders, the database check, Scan Library, Reorganize Library and the Default library location pointer) is a tab under Library too. Schedules (reject words, preferred language and the search, Hardcover sync, library scan, release discovery and series check intervals) sits under System. Every setting keeps its key, its auto save toast and its current value line. Links to a setting by key, such as `/settings?tab=general#import.mode`, still land on the field, and Settings search now points at the new tabs. The setup checklist storage warning opens Storage. A link that names `?tab=general` with no setting key still opens General.

### Fixed
- **A blocklist entry for one book no longer blocks that release for every book** (#3563). When a release was blocklisted for one book, because its quality or metadata profile refused the file or because someone blocklisted it from that book's History, search refused the release for every other book that wanted it too, including another account's book whose profile allowed it. Automatic and interactive search now apply such an entry to its own book only. A release the download client failed as broken or reported stalled, and anything imported from Readarr's blocklist, is still blocked for every book. Existing entries are sorted the same way when you upgrade.

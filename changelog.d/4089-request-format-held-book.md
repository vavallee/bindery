### Changed
- **A request for a missing format of a book the requester can't change now waits for an admin** (#4089). With `BINDERY_ENFORCE_TENANCY` on, a requester or user who asked for the audiobook of a book the library holds only as an ebook got a 409 when that book was shared or belonged to another account, so the request never reached the admin's queue. It is now created as pending and is never auto approved, whatever the account's auto approve setting or the system default says, so the book is left alone until an admin decides. An admin approving it adds the format to the existing book, which keeps its owner, and searches if search on add is ticked. A request whose formats such a book already covers is still refused as already in the library, and installs with enforcement off are unchanged.

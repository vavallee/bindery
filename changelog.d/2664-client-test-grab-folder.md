### Fixed
- **Download client Test and health check look where grabs actually land** (#2664). For rTorrent they checked the client's own default directory, but every grab is sent its own folder built from your download directory, so a seedbox whose default folder Bindery cannot see was reported as unable to import on a setup that imports fine. For a qBittorrent category with an empty save path, Test checked the default save path itself, and the health check failed outright, although qBittorrent saves those downloads to the default save path plus the category name. A qBittorrent client with no category failed the health check as "category is empty" while Test passed it. Both now check the same folder **Diagnose** reports, a relative category save path is resolved under the default save path, and a category folder qBittorrent has not created yet passes when the folder it will be created in is readable.

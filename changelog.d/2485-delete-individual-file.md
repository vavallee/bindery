### Added
- **Delete one file of a book from disk** (#2485): each tracked file on the book page now has Delete this file in its More menu, under Forget this file. It deletes only that file, removes its tracking row, prunes the folder if it is left empty, and records the deletion in history; other files on the book are untouched. The same library root and ownership checks as the other delete actions apply, and if the file cannot be safely removed Bindery says so instead of pretending it worked. Forget this file still only stops tracking without touching the disk. Thanks trevorswanson for building it.

### Fixed
- **Transmission queue polls fetch the torrent list once** (#3714). With an audiobook category set, the Queue page overlay, the stall check and the import poll pulled the whole torrent list from Transmission once per category, and the import poll sometimes a third time. They now fetch it once and filter locally with the same matching rule, which halves the work on big sessions.
- **qBittorrent proxy login stays on https** (#3703). The reverse proxy credentials are now only sent with the scheme you configured, so an https client never sends them over plain http to the same host and port.

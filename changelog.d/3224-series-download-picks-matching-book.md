### Fixed
- **A download holding several books imports the one it was grabbed for** (#3224): when several ebook files of one format would land in the same place, the one whose file name or EPUB title clearly matches the book is placed, rather than whichever came first on disk. Names that say nothing keep their order. The external drop folder does the same, in its flat and templated layouts.
- **More multi-book pack names are recognised** (#3224): `Foundation series by Isaac Asimov` with only pack or format words or a list of titles after the author, `Discworld Series 1-41`, `Series - Isaac Asimov 1-7`, a bracketed count of two or more such as `(11 Books)`, `Books Collection` (plural only), `Series Pack` and `Saga eBooks` are no longer auto-grabbed for a single book. A title after the author, as in `Discworld Series by Terry Pratchett - Guards! Guards!`, still is.
- **Release notes are not imported as a book format** (#3224): an ebook file under 4 KiB in a download, like the 253 byte `.txt` some releases ship beside the book, is skipped instead of being tracked and pushed to Calibre. A download holding nothing else is blocked with a pointer to manual import, also with an external drop folder. Manual import still places a file that small, managed or drop, including when it is held for the other format of a book set to both.

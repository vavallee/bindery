### Fixed
- **Re-running an author import no longer duplicates authors linked to another provider** (#2117, reported by TheOpsMgr). The Readarr import and the pasted or uploaded author list only recognised an existing author by provider id, so an author linked to DNB during an OpenLibrary outage, or added on a Hardcover primary, was added a second time once OpenLibrary answered with its own id. An author already in your library under the same name is now skipped, whichever provider it is linked to. Nothing is merged or changed; use Merge on the author page for duplicates you already have.
- **Authors added from DNB or Hardcover are labelled with the right provider** (#2117). When the provider could not be asked for the author's details (DNB has no lookup by id at all), adding a book or an author, or mapping an Audiobookshelf author by hand, labelled the new author as an OpenLibrary author whatever its id said.

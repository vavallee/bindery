### Added
- **Add a book by hand** (#3840). The Add to library dialog has an **Add by hand** step for a book no metadata source knows, such as a short story, an anthology piece or a fan translation: type the title and author, and optionally a series with the position, the format and whether to search. Nothing is looked up. An author already in your library is reused and any other name becomes an author with no metadata, which Link metadata connects later. Metadata refreshes leave these books alone, an author refresh that finds a work with the same title neither attaches it to the book nor adds a second copy, and Re-bind links one to a real record when you want. The API is `POST /api/v1/author/book/manual`.

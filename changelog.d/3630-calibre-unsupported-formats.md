### Fixed
- **Calibre import no longer tracks files Bindery can't use** (#3630). The library import used to add a book file for every format Calibre lists, so the `ORIGINAL_EPUB` backups that Polish and Fix EPUB keep showed up as ebooks you couldn't open, remap or deliver, and came back after you removed them. It now tracks only the formats the library scan accepts plus PRC, KEPUB and AAC, and your next Calibre import stops tracking the backups that imports from v1.35.0 on picked up. Backups picked up by v1.32.2 to v1.34.x aren't cleared automatically, but you can remove them by hand and they now stay removed. Nothing is deleted from disk, and rows a download, a scan or you added are left alone.

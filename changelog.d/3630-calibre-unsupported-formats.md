### Fixed
- **Calibre import no longer tracks files Bindery can't use** (#3630). The library import used to add a book file for every format Calibre lists, so the `ORIGINAL_EPUB` backups that Polish and Fix EPUB keep showed up as ebooks you couldn't open, remap or deliver, and came back after you removed them. It now tracks only the formats the library scan accepts, and your next Calibre import stops tracking the backups earlier imports picked up. Nothing is deleted from disk, and rows a download, a scan or you added are left alone.

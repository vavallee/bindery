### Fixed
- **A download with several ebook formats now shows the preferred one even when it was imported last** (#4142). When one download held, say, a PDF, an AZW3, a MOBI and an EPUB, the book could end up showing the AZW3 as its file instead of the EPUB. Bindery picked the format to show while the newest file was still being put in place, so the file imported last was never considered, and a library scan was needed to correct it. The choice is now made again once each file has landed, so the book shows the most preferred format (EPUB, KEPUB, AZW3, MOBI, PDF) straight after the import. All the files were always imported and tracked; only the one shown on the book was wrong. Thanks to FazalAAli for the report and the diagnosis.

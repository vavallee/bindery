### Fixed
- **Audiobookshelf import no longer relinks books to a fallback provider while the primary is down** (#2642): the import matches each item to an upstream book by ISBN across the metadata providers. When the primary provider timed out, a fallback such as DNB or Hardcover answered instead, and the book was moved onto that provider's id for good, which could leave a duplicate once the primary came back. The import now leaves the book on its current identity and says on the item that the relink was skipped because the primary did not answer, so the next import tries again. The rest of the item still imports as usual, and a primary that answers with no record for the ISBN still lets the other provider's record through.

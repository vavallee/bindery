### Fixed
- **A book only Google Books knows can be added again** (#3538, thanks ngoc-minh-do). Add Book used to answer "Author metadata unavailable" for a Google Books title whose author OpenLibrary has never heard of, and the "Add Author by name" it pointed to could not create the author either. When OpenLibrary is on, answers, and has no record of the name at all, Bindery now makes the author from the name on the volume and adds the book, and a second book by the same author reuses it. With OpenLibrary off, failing, or holding a same name record, the message stays. Refresh still asks Hardcover and Audible by name for such an author, two different people with the same name share one author, and the same person found later on OpenLibrary is a second author to merge by hand. Adding an author from a typed name on the Authors page is still not possible for an author no provider knows.

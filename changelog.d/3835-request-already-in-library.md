### Fixed
- **Approving a request for a book that is already in the library works again** (#3835). If someone else added the book while the request waited, approving used to answer that the book is already in the library, and nothing else could be done with the request. Now, if the request asked for a format the book does not have or monitor yet, approving monitors that format on the existing book and searches for it. If the book already has everything that was asked for, approving adds nothing and simply resolves the request, and the Requests page tells you so. Pending requests the library already covers get an "Already in the library" badge. Approving a format on a book its owner skipped makes that format wanted again. With multiple accounts, a book another account added no longer blocks the request when it already covers what was asked; only a missing format on someone else's book is still refused, and the request can be declined. Declining always worked. Author requests are unchanged. Thanks to flaevers for the report.

### Security
- **An audiobook folder download only contains that audiobook** (#3587). Downloading an audiobook as a zip, from the web app or over OPDS, packed every file in its folder, so a file another book tracks inside that folder (with separate libraries per user, possibly another user's ebook) came along with it. Files and folders another book tracks are now left out, also when the two are spelled in different case. Cover art, cue sheets and other untracked files in the folder are still included.
- **Download client errors are only shown in full to admins** (#3587). When a download client could not be reached, or refused a release, the queue and History showed every account the client's own error, which names its address. Accounts that are not admins now see the client's name and a short message instead, including for older entries. Admins still get the full error in the queue and the log. New History entries and failure notifications carry the short message for everyone.
- **An import blocked by another user's book no longer names it** (#3587). With `BINDERY_ENFORCE_TENANCY` on, a download whose destination is already tracked by a book that belongs to someone else now says another book in the library uses that path, without that book's title or id. The import is still blocked as before.

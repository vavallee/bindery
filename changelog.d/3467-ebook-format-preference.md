### Fixed
- **A book with several ebook formats now serves the EPUB first** (#3467). When a release held, say, AZW3, EPUB and MOBI, the book's main file was whichever was imported first, so OPDS and downloads handed out the AZW3. The main file now follows one order: EPUB, KEPUB, AZW3, MOBI, PDF, then anything else, and a library rescan fixes books already imported the old way. Every file is still kept. This is deliberately EPUB first, so the file served and offered follows EPUB first even where a quality profile ranks AZW3 higher for searching, and a Kindle focused order from the quality profile is a possible follow up. Thanks to kennethp1015 for the report.

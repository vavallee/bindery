### Changed
- **Status colours come from one place** (#3994). Success, warning, danger, info, progress and caution colours, the green accent on primary buttons and focus rings, the blue of links, and the white text on solid fills are now named colour variables with light and dark values in the web UI's stylesheet, instead of amber, red, emerald, blue, orange and sky classes repeated across about 100 files. Colours are the same or very close, with a few small visible differences: alert and banner tints are slightly stronger, one hover over them is a little darker, and chip text in the dark theme is a lighter shade for better contrast. The contrast test measures each pair in both themes and fails if one drops under the WCAG AA minimum. A new test fails when a raw colour class, an arbitrary colour value or a class built at run time is added outside a short list of category colours such as the ebook and audiobook badges, so an accent or theme change is a one file edit.

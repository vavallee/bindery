### Changed
- **Status colours come from one place** (#3994). Success, warning, danger, info and progress colours, the green accent on primary buttons and focus rings, and the white text on solid fills are now named colour variables with light and dark values in the web UI's stylesheet, instead of amber, red, emerald, blue and sky classes repeated across about 100 files. The look is the same, apart from a few tints that now share one shade per status, and the contrast test measures each pair in both themes and fails if one drops under the WCAG AA minimum. A new test fails when a raw status colour class is added outside a short list of category colours such as the ebook and audiobook badges, so an accent or theme change is a one file edit.

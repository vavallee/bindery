### Fixed
- **Language filter missing names joined to another word** (#3497) - a release like `Dungeon Crawler Carl_EspañolNeutro m4b` slipped past an English only metadata profile because the language word was glued to another word. A language name at the start or end of a capitalised joined word (EspañolNeutro, DeutschUngekürzt, ItalianoAudiolibro) is now read like a standalone one. Two letter codes are still never read inside a word. This covers the release name only; checking the language tag of an audiobook file at import is still to come. Thanks to jh11-web for the report.

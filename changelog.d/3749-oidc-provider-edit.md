### Fixed
- **Adding or removing an OIDC provider no longer wipes the others** (#3749). Settings sent every saved provider it had not added in the same visit back with a blank issuer, client ID and scopes and no allowed groups, so adding or removing one provider broke all the others until they were set up again. It now sends each one back exactly as saved, and Bindery refuses a save that would clear a saved provider's issuer or client ID. If a provider stopped working after such a change, edit it and fill in its issuer, client ID and client secret again.

### Added
- **Edit a saved OIDC provider in place** (#3749). Each provider in Settings has an Edit button that opens its form filled in, including a new Allowed groups field (one group per line). Leave the client secret blank to keep the saved one. Before this the only way to change a provider was to remove it and add it again, which also dropped its allowed groups. Two safety rules come with it: a save that leaves out allowed groups keeps the saved ones (only clearing the list empties them), and changing a provider's issuer needs its client secret again, so a saved secret is never sent to a different identity provider.

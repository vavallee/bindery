### Fixed
- **Reorganize no longer carries another book's file away with an audiobook folder** (#3556). When an audiobook folder also holds a file a different book tracks, Rename files now shows it as an error with the reason and leaves it in place, instead of moving the folder and leaving that other book pointing at a path that no longer exists. An audiobook import no longer joins an ebook folder that also holds another book's ebook and gets a folder of its own instead. Fix match and manual import of an audiobook folder that holds another book's file are refused with the same reason.

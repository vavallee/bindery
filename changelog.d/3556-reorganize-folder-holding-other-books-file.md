### Fixed
- **Reorganize no longer carries another book's file away with an audiobook folder** (#3556). When an audiobook folder also holds a file a different book tracks, Rename files now shows it as an error that names the file to move out and leaves the folder in place, instead of moving it and leaving that other book pointing at a path that no longer exists. An audiobook import no longer joins an ebook folder that also holds another book's ebook and gets a folder of its own instead. With import mode set to move, Fix match of such an audiobook folder is refused up front, before the file is detached from its book, and the Fix match dialog no longer offers that move. Copy and hardlink imports leave the folder where it is and go ahead as before.

### Added
- **Import History records where each file came from** (#3248). Import rows in History now note their origin, either a download or a manual import. For downloads they keep the release guid and download id, plus the indexer and download client when Bindery knows them, and ebook import rows list the exact library paths they placed. Because import rows from a download now carry the release, the History blocklist API (`POST /api/v1/history/{id}/blocklist`) accepts them too; the History page does not show a Blocklist button for them yet. This first slice covers downloads and manual imports only; folder handoff and library scan imports do not record provenance yet.

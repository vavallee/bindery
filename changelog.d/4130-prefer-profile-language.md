### Changed
- **Releases in your profile's language now rank higher** (#4130). When a metadata profile lists allowed languages, a release whose name is tagged with one of them is ranked above an untagged release, enough to outweigh a better format or a RETAIL tag. Before, the language setting could only drop wrong language releases, so an untagged English release often won over the tagged German ones for a German library. This includes the default profile, which allows English: on a default install a release tagged English now beats an untagged one of a better format. Only a profile that allows any language ranks exactly as before. An exact ASIN or ISBN match still outranks a language only match. Thanks to BraynArts for the report.

### Fixed
- **Ebook content check now catches another book by the same author** (#3461): with the check on, a file whose title is a different book of the wanted book's author, like the next volume in a series, used to pass because the author matched. It is now flagged when the file's title is another book in that author's catalogue, and refused in block mode when that book is at a different position in the same series. When Bindery cannot tell it from another edition of the wanted book it only notes it. Warn mode still only notes it, and translated or alternate titles that are not a separate book in the catalogue are left alone. Thanks to kennethp1015 for the report.

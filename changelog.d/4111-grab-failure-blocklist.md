### Fixed
- **A torrent whose indexer keeps answering with a server error is now blocklisted** (#4111). When an indexer answered a release's download link with a 5xx such as Prowlarr's 500 "Download failed", Bindery paused the indexer but never held it against the release, so the same release was grabbed again every six hours for ever and the book never moved on to another one. A 5xx now counts like a 404: three failures at least an hour apart blocklist the release, but only while the indexer is otherwise serving and no other release from it failed, so an indexer that is down is still only paused. A 429 or a "disabled till" notice still never counts, since a daily quota looks the same as a dead link. Thanks to highlander-phill for the report.

### Fixed
- **Reorganize now refreshes metadata.opf for books that are already in the right place** (#4008). Thanks to coppit for the report. With the metadata.opf sidecar setting on, Reorganize used to write one only for a book it renamed or moved. It now covers every book, so a whole library ends up with matching sidecars. It only writes a file that is missing or that Bindery wrote itself, leaves one from Calibre, Audiobookshelf or a hand edit alone, and does not rewrite a file that is already up to date. The result shows how many were written and how many skipped. Formats in External import mode are skipped, and with the setting off nothing changes.

### Security
- **Saved Grimmory, Audiobookshelf, BookOrbit and Calibre plugin credentials are cleared when the server address changes.** Changing the Grimmory server URL without entering a new API key or password now clears the saved ones instead of keeping them for the new address, so enter them again after moving to a different server. The same now holds when one of these addresses is changed through the Advanced settings screen or the generic settings API, and the Grimmory test button no longer sends saved credentials to an address that has not been saved. Moving between spellings of the same address, such as a trailing slash, capital letters in the host or an explicit default port, keeps the saved credentials.

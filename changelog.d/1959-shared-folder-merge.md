### Fixed
- **Audiobook import no longer splits into a "Title (2)" folder when the ebook is already there** (#1959) — under the shared-folder layout (`BINDERY_AUDIOBOOK_DIR` unset, so both formats resolve to the same folder), importing a book's audiobook after its ebook now merges into the book's existing folder instead of creating a sibling duplicate. A same-named file already in the folder (e.g. cover art carried by both formats) is skipped rather than overwritten, and the skipped names are recorded on the import's History entry and `bookImported` notification. Libraries using the per-file audiobook naming template or multi-disc flattening are unchanged for now and still split — those paths create and own their destination folder, and merging them safely needs their rollback reworked first.

### Fixed
- **A file already handed off in External mode is no longer offered again** (#3948). With a drop folder and copy or hardlink placement, importing a file from a folder copies it into the drop folder and leaves the original where it was. Rescanning that folder then listed the original under Matched, already ticked, so one click dropped a second copy. It is now left out while its download is waiting on your import tool, and Show already imported lists it as already handed off, unticked. It comes back as a normal match once the drop fails or is blocked, or you remove the row from the Queue.
- **History now shows which file an External drop placed** (#3948). The Folder Imported row for an ebook named only the drop folder, so there was no telling which file was dropped. It now names the file itself, and for an audiobook the folder it was dropped into.

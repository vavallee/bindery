### Added
- **Current value under each Settings label** (#3989). Settings that hold a choice, a switch or a value, and the fields in the Edit Author dialog, now show what is set right now in a quiet line under the label, such as "Current: Hardlink" or "Current: Default (12 hours)". The line reads the same state as the control, so it changes when a save lands and goes back if a save fails. Secrets such as API keys and tokens only ever show Set or Not set, and long folder paths are cut to one line with the full path on hover. Fields with their own Save button are not included, since what you typed there is not saved yet.

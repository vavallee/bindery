### Added
- **Current value under each Settings label** (#3989). Settings that hold a choice, a switch or a saved value now show what is set right now in a quiet line under the label, such as "Current: Hardlink" or "Current: Default (12 hours)". The line reads the same state as the control, so it changes when a save lands and goes back if a save fails. The Edit Author dialog has the same line under its profile, root folder and monitor fields, showing what is saved for that author, so it does not move while you pick and shows the new value the next time you open the dialog after saving. Secrets such as API keys and tokens only ever show Set or Not set, a saved URL never shows a user name or password, and long folder paths are cut to one line with the full path on hover. Fields with their own Save button are not included, since what you typed there is not saved yet.

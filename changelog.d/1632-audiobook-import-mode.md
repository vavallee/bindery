### Added
- **Audiobooks can have their own import mode and drop folder** (#1632): Settings, General, File Naming has a new Audiobook import mode under the Import Mode buttons. It defaults to Same as ebooks, so nothing changes until you set it. With Calibre-Web-Automated and Audiobookshelf you can now set Import Mode to External with CWA's ingest folder as the drop folder, and the audiobook mode to Copy, Hardlink or Auto: ebooks go to CWA, audiobooks land in your audiobook folder and Bindery triggers the Audiobookshelf scan, instead of CWA filing the m4b into the Calibre library. Copy works on storage that cannot hardlink, such as an Unraid mergerfs pool. When audiobooks are External too, an optional Audiobook drop folder sends them somewhere other than the ebook drop folder.

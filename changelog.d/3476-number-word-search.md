### Fixed
- **Search finds "Book One" titles named "Book 1"** (#3476). A book whose title spells a position out (`Path of the Deathless Book One`) never found a release that uses the digit on indexers that need every query word, such as MyAnonamouse. When a search finds nothing relevant, Bindery now sends one extra query with the digit form, and the relevance check treats `Book One` and `Book 1` (book, volume, part, season and similar, one to twenty) as the same position while still rejecting `Book 10` and `Book 2`. The debug panel shows the extra query per indexer. A book that stays unfound pays that one extra query per indexer on every scheduler cycle. Thanks to the reporter for the detailed trace.

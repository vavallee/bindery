### Added
- **slskd client, first step** (#1717). You can now add slskd, the Soulseek daemon, as a download client in Settings. Test and Diagnose check that slskd answers, runs 0.26.0 or newer, is logged in to Soulseek, that the API key has a write role, and that its downloads folder is readable through your path remap. Whether a port is forwarded cannot be detected, so that row is informational only. Nothing searches or downloads through slskd yet, so this release only lets you set it up. It is opt in, and the deployment guide covers setup and what Soulseek exposes about you.

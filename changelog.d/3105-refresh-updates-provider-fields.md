### Changed
- **Refreshing an author now corrects the release date of books you already have** (#3105). Until now a date fixed upstream never reached a book that was already in your library unless you re-bound it by hand. This changes behaviour for every install: on an author refresh, a book from the same provider that the provider's record identifies by its own id takes the provider's current release date when it differs, and gets a description if it has none. The year feeds the `{Year}` naming token and the search year, so a corrected date can change a folder or file name the next time that book is imported or reorganised. A refresh never empties a field, never changes a field you edited (those are locked) or one you settled on the Audiobookshelf conflicts page, never replaces a description you already have, and skips excluded books, books from another provider, and books matched by title. Language is not updated. If you want a date to stay, edit it so it locks.

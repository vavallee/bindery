### Changed
- **Refreshing an author now updates the books you already have** (#3105). Until now a correction made upstream to a release date or language never reached a book that was already in your library unless you re-bound it by hand. This changes behaviour for every install: on an author refresh, a book from the same provider takes the provider's current release date and language when they differ, and gets a description if it has none. A refresh never empties a field, never changes a field you edited (those are locked), never replaces a description you already have, and skips excluded books and books that came from another provider. If you want a value to stay, edit it so it locks.

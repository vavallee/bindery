### Added
- **Narrator, duration and ASIN can be locked** (#3216). Editing any of the three on a book through the API or the ASIN box locks it, the way title and description already locked, so Audiobookshelf re-imports, Audnex enrichment, Hardcover hydration and Hardcover list syncs keep your value.

### Changed
- **The ASIN re-map inside Enrich keeps your locks.** (#3216) It used to clear every lock as if you had re-bound the book. Re-bind still clears the work-field locks (title, description, genres, language, release date) but keeps narrator, duration and ASIN locks, because it keeps those values.
- **Rolling back an Audiobookshelf import leaves a locked narrator, duration or ASIN alone** (#3216), even when the value still matches what the run wrote. The import's book writes and the Hardcover list sync's widen now refuse a stale snapshot, so a lock set while a run is in progress is kept.
- **API clients that send `narrator`, `asin` or a positive `durationSeconds` on `PUT /book/{id}` now lock those fields** (#3216), an empty `narrator` or `asin` included, the way an empty `description` already locked; a client that reads a book and writes the whole object back locks narrator and ASIN, and duration when it is above zero, unless it also echoes `lockedFields`, which replaces the lock set as it always has. `asin` is normalized to upper case and, when it changes, must be ten letters or digits (400 otherwise); writing back the stored value is always accepted. `durationSeconds` was ignored before; `0` still means not set, and a negative value is a 400. "Unlock all fields" in the edit dialog also unlocks narrator, duration and ASIN.
- **A lock set from the ASIN box shows only the page's general lock badge** (#3216); the edit dialog badges its own five fields and offers "Unlock all fields". A per-field badge beside the ASIN box is a follow-up.

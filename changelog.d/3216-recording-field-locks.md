### Added
- **Narrator, duration and ASIN can be locked** (#3216). Changing any of the three on a book through the API or the ASIN box locks it, the way title and description already locked, so Audiobookshelf re-imports, Audnex enrichment, Hardcover hydration and Hardcover list syncs keep your value. Thanks chemicalsno.

### Changed
- **The ASIN re-map inside Enrich keeps your locks.** (#3216) It used to clear every lock as if you had re-bound the book. Re-bind still clears the work-field locks (title, description, genres, language, release date) but keeps narrator, duration and ASIN locks, because it keeps those values.
- **Rolling back an Audiobookshelf import leaves a locked narrator, duration or ASIN alone** (#3216), even when the value still matches what the run wrote. The import's book writes and the Hardcover list sync's widen now refuse a stale snapshot, so a lock set while a run is in progress is kept.
- **Narrator, duration and ASIN lock on `PUT /book/{id}` when their value changes** (#3216). Sending a field with the value it already has locks nothing, so a client that reads a book and writes the whole object back changes no locks, and `{"asin": ""}` on a book with no ASIN is not a lock. Naming a field in `lockedFields` still locks it without a change. The same rule now applies to title, description, genres, language and release date. `asin` is normalized to upper case and, when it changes, must be ten letters or digits. `narrator` is capped at 1000 bytes and `durationSeconds` at 3600000 (1000 hours); both are a 400 above that. `durationSeconds` was ignored before; `0` still means not set, and a negative value is a 400. "Unlock all fields" in the edit dialog also unlocks narrator, duration and ASIN.
- **`releaseDate` on `PUT /book/{id}` also takes the RFC 3339 timestamp GET returns** (#3216), so writing back a book you just read no longer fails with a 400.
- **A lock set from the ASIN box shows only the page's general lock badge** (#3216); the edit dialog badges its own five fields and offers "Unlock all fields". A per-field badge beside the ASIN box is a follow-up.

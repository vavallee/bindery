### Fixed
- **calibredb mode says so when there is no calibredb** (#1940). The official Bindery image does not include Calibre, so with the write integration set to calibredb CLI nothing ever reached Calibre, while every import looked successful and the only trace was one line in the log. Now saving that mode answers with a warning when calibredb cannot be found, and the Calibre settings tab shows it whenever it opens in that mode, with a button to switch to the Calibre Bridge plugin. **Test connection** gives the same reason. Books imported in the meantime wait in the delivery queue without using up their retries, and its status line names the missing calibredb, so they go to Calibre once calibredb is installed or the Bridge plugin is set up. Thanks to drcrypt for the report.

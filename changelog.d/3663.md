### Added
- **Narrator and edition preferences for audiobooks** (#3663). A quality profile can now prefer narrators and either prefer unabridged editions or reject abridged ones, both off by default so nothing changes until you set them. Interactive search shows the edition type and narrator a release name states, and the book page shows the narrators and edition type of its audiobook edition when Audiobookshelf supplied them. Editions now store a narrator list and an edition type. Refs #1358.

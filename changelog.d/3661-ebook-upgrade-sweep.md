### Added
- **Ebook format upgrades** (#3661). A quality profile can now upgrade ebooks: tick "Upgrade ebooks that rank below the cutoff", pick a cutoff such as EPUB, and Bindery searches again for imported ebooks that only have a lower format, like a MOBI, and imports the better one. It is off by default, and profiles that existed before this release were switched off on update, so nothing changes until you opt in. The old file is kept next to the new one unless you also tick "Delete the old file after a verified upgrade". An upgrade is held to a stricter content check than a normal import: if the new file turns out to be a different book it is refused and blocklisted, and the file you have is never touched. A finished upgrade fires the Upgrade notification. Audiobooks are not upgraded. Thanks to kennethp1015 for the request and for the rule that a wrong book must never replace a good file.

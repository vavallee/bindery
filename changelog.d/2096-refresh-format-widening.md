### Fixed
- **An author refresh no longer changes the format of a book you already own** (#2096) — when a catalogue listed the same work in the other format, the refresh merged the row to dual-format whether or not the book was already on disk. Since a book's status is derived from the formats still missing, that quietly invented a want nobody asked for and dropped the book off Imported and back onto Wanted, with its file untouched. One reporter had a single routine refresh flip 29 owned books, some added two months earlier. The merge still runs for a book nobody has yet, which is the duplicate-row problem it exists to solve. Books already widened keep their media type; set one back by hand and the status follows.

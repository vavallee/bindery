### Added
- **Reject import** (#3250). A bookImported row in History and on the book page now has a Reject import button, requested by foobarbigtime. One confirmed action detaches the imported file, blocklists the release it came from for that book and puts the book back on Wanted, all or nothing. The file is deleted from disk only when it is inside a library folder, otherwise it is just untracked, and an import that recorded no release is still rejected without a blocklist entry.

### Changed
- **The book page no longer devotes a red section to deleting a book.** Deleting a book and its files had a heading, a full width tinted card and the only solid red button on the page, for one action. The author page has always carried the same action as a red item in its More menu, so the two pages disagreed about what deleting a thing looks like and the book page shouted. It now matches: Delete book and files sits at the bottom of the More menu, in red, with the same confirmation as before. Nothing is harder to reach, and unlike the other items in that menu it stays available on a book with no files, because a wanted book is still a book you may want to delete.
- **Three more notices now use the shared alert component.** The Fix match warning, the catalogue reconciliation partial warning and the Calibre rollback files warning each drew their own amber box, which is what the shared component was added to stop. They now take their colour and their spacing from the same place as every other notice.

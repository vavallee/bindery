### Fixed
- **A book's language is stored the same way whatever it came from** (#3086). Google Books, the Audiobookshelf import, the Calibre import and the book edit form saved the language exactly as it arrived, so one author could have books marked `en`, `english` and `eng`, or `deu` and `ger`, side by side in the API, the OPDS feed and anything grouping by language. All of them now save the three-letter code the other sources already use, and existing books and editions are brought into line once on the first start after upgrading. A language Bindery does not recognise is kept, in lower case, rather than dropped. The Norwegian codes `nob` and `nno` both become `nor`, which is visible on Norwegian libraries, and the National Library, OpenLibrary and DNB providers are covered too because the language is now settled when a book or edition is written, not by each source.

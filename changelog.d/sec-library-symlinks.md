### Security
- **Symlinks from a download can no longer reach your library or leak files.** A move mode audiobook import now drops any symlink or special file that came with the download instead of carrying it into the library. Book downloads, audiobook zips, OPDS and the Calibre bridge refuse to follow symlinks and only serve regular files inside your library folders, and Library Scan no longer attaches a symlinked file to a book. A library folder that is itself reached through a symlink or a bind mount keeps working. Filenames containing a backslash or quote are now escaped properly in download headers.

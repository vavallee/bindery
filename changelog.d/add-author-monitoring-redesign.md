### Changed
- **Add Author shows its monitoring controls and says what will happen before you press Add.** Monitor mode sat behind a closed "Customize monitoring" disclosure with no explanation of any option, so the recurring question "I added one author and now have 100 wanted books" kept coming back. The controls are now simply on the screen, the way Readarr shows them, each with a line saying what it decides. A new line under them states the outcome: how many books are about to be added and, for the mode you picked, which of them Bindery will search for. It changes as you change the mode.
- **Monitor new items can be set when adding an author**, not only afterwards. "Catalogue this author once and never let a refresh grow it" was not expressible at add time before. `POST /api/v1/author` accepts `monitorNewItems` with the same values as the update endpoint.
- **"Future books only" now says it grows on refresh.** Nothing scheduled discovers an author's new releases yet (#2236); they join the catalogue when you refresh the author. The label no longer implies otherwise, and the same correction is made in the user guide's first quick answer, which recommended the mode without saying so.

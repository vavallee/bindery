### Added
- **A default for auto approving requests** (#3900). There is now a system wide setting, `requests.auto_approve_default` in Settings, Advanced, that decides whether requests approve themselves for every account without a setting of its own. It is off, so nothing changes on upgrade, and accounts that already had auto approve on or off keep exactly what they had. On the Users page each requester now picks Use default, Always or Never, and you can see what that account gets today. A request for a book already in the catalogue still waits for a person, and the daily ceiling still applies. Thanks to jviall for the request.

### Fixed
- **Books titled "Series, Book N: Subtitle" now find releases named by the subtitle alone** (#4183). A book such as `Path to Transcendence, Book 1: Will of Mana` stayed Wanted on indexers that need every query word in the release name (MyAnonamouse through Prowlarr), because every query carried the series and the position and the release is named `Will of Mana by Ryan Arelius`. When a search ends without a relevant result, Bindery now sends one more query per indexer made of the author's surname and the subtitle (`Arelius Will of Mana`). A result from it is kept only when it names the whole subtitle and the author, so another author's book with the same title is not picked up. It is sent only when the part before the colon ends in a position number and the subtitle is specific enough (not `A Novel` or `Book Two`), it counts against the indexer's daily query cap, and it shows in the search debug panel as `subtitleQuery`. Thanks to huepotman for the report and the indexer logs.

### Fixed
- **Box sets and omnibuses no longer need Hardcover configured to be caught, and dropping one is now opt-in and visible.** Catching a box-set/omnibus "work" from a primary provider like OpenLibrary used to rely entirely on Hardcover's compilation classification, so a default OpenLibrary-only install got no pruning at all. An earlier fix for this ran a second, broader title-shape heuristic unconditionally in the aggregator, with no way to turn it off and no count surfaced anywhere it could be seen — on review, two heuristics for one concept at two layers was the wrong shape, since they inevitably drift. Author sync now relies solely on `SkipPartBooks`'s existing `isPartBookTitle` filter for this, which already runs against every provider's works (not just OpenLibrary's), is opt-in, and reports what it drops via the author page's sync notice.

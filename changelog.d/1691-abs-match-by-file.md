### Fixed
- **Audiobookshelf import matches a book by its files before its title** (#1691, reported by gavinmcfall). When Bindery already had a book with the item's file tracked, for example one it downloaded itself, and the Audiobookshelf title was spelled differently ("Chapter House Dune" against "Chapterhouse: Dune"), the import created a second book that could never take the file and so stayed wanted beside the one you own. The item is now matched to the book that already holds its file, as long as both credit the same author. That book keeps its own author and title. Retitling an item in Audiobookshelf and importing again already updates the same book.
- **Review duplicates finds titles filed with the article behind a comma** (#1691, reported by gavinmcfall). "Trace of Death, A" and "A Trace of Death" are now offered as one group. As before, nothing is excluded until you confirm it.

### Fixed
- **qBittorrent grabs no longer adopt someone else's torrent** (#3536). When Bindery had to work out which torrent it had just added, it picked the newest new one, and torrents have only one second timestamps. A torrent added by another tool in the same second could win, and Bindery would then move it into the books category and track it as the grab. Each add is now tagged with a unique marker and Bindery only accepts the torrent carrying it (the tag is removed again afterwards). A failed list read before the add no longer makes every torrent a candidate, and if several new torrents cannot be told apart the grab fails instead of guessing. Thanks to jdcrensh for the report.
